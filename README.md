## 🧭 Comment utiliser ce dossier

1. **Ouvre-le dans Obsidian** : *Ouvrir un dossier comme coffre* (ou avec VS Code, qui affiche le rendu).
2. **Avant chaque séance**, lis la fiche (5 minutes).
3. **Pendant la séance**, travaille avec la fiche à côté de toi.
4. **À la fin**, remplis ton **journal de bord** et fais un **commit Git**.
5. **Copie sur ton propre espace** les modèles à remplir (journal, tableaux) : ne modifie pas le dossier partagé.

---

## 🎯 Les 4 choses à retenir

1. **Deux réalisations opérationnelles** : une absente coûte **10 points**.
2. **17 compétences à prouver** : chacune doit avoir une trace dans ton dossier.
3. **Un laboratoire conforme à l'annexe II.E** : une non-conformité coûte **jusqu'à 15 points**.
4. **Un dossier déposé à temps** : hors délai, c'est la note NV et pas de diplôme.
